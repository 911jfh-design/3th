# جوال ملقوط · FoundPhone Studio

إطار قصص تفاعلية على جوال افتراضي. الواجهة معرّبة بالكامل، والقصة الافتراضية **جوال هدى**.

## القصة
هدى تجهّز عرس أختها أمل (العريس سعود) مع إخوانها وأخواتها، والعروس ما تدري أن العرس عرسها يوم الجمعة 20/11 في قاعة الياسمين.
أمل ترسل لهدى وتشك أن في شي مخبّى، والقارئ هو من لقي الجوال وفتحه.

## المسار
1. اقرأ رسالة هدى في مجموعة «عرس أمل 🤫» التي فيها رمز الخطة: `2011`
2. افتح ملاحظة «خطة مفاجأة أمل 🔒» بالرمز
3. تظهر رسالة القاعة وصورة الفستان وموعد العرس الحقيقي
4. اقرأ آخر رسالة من أمل فتتصل بك
5. ثلاث نهايات: حافظت على السر، أو ارتبكت وقلت مبروك، أو قلت الحقيقة

## التشغيل
```
npm ci
npm run story:validate
npm run story:test
npm run story:preview
```
ملف القصة: `stories/huda-surprise/story.json` (ونسخة منه في `stories/template/story.json`).

## ملاحظة
اختبارات `tests/` و`*.test.ts` القديمة مكتوبة بنصوص الواجهة الصينية، فتحتاج تحديث النصوص لتنجح بعد التعريب.
